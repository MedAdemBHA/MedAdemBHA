## 🏗 What I build & run

**[Monasabty](https://monasabty.com)** — Co-Founder & Lead Engineer · *live in production*
> Tunisia's first structured B2B marketplace for event services. **500+ verified providers**, **1,200+ events organized**.
> One NestJS API serving four clients: React dashboard, Next.js marketplace, and an Expo mobile app.
> Booking and payment lifecycle end-to-end — deposits, quote negotiation, and a four-role permission system.
> Runs on Docker + Nginx with GitHub Actions CI/CD and Prometheus/Grafana/Loki observability.

**Loopra** — Founder & Lead Engineer · *live in production*
> Coaching-operations SaaS. Migrated from a Supabase MVP to a fully owned NestJS/Prisma runtime on PostgreSQL,
> with schema separation, BullMQ job queues, and Socket.io realtime, self-hosted behind Nginx.
> Flutter mobile client and React/MUI dashboard against one backend, with the OpenAPI spec generating the typed client.

**[docflow](https://github.com/MedAdemBHA/docflow)** — Open Source · *MIT*
> A documentation-memory plugin for AI coding agents (Claude Code, Codex). Scaffolds structured project docs
> and an append-only changelog, then loads them into the agent's context at the start of each session.
